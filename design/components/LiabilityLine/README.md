# LiabilityLine

The block that marks the moment liability moves. It sits directly above the receiver's Sign button on the acceptance screen, and nowhere else.

A 2dp `signal-edge` box: on the left a 44dp column of `on-signal` and `signal` hazard stripes; on the right the regulatory line in bold uppercase mono `signal-text` (THIS IS SEALED SOURCE IR-0457), then one sentence in `body` that says what signing does ("By signing, you accept liability for C-12 from 13:02."). The time is the phone's current time and updates each minute.

The primary button below it names the act: SIGN AND ACCEPT C-12.

The consumer provides: the source ID, the item ID and the current time.

Don't: shorten the sentence, move it away from the Sign button, or use it on the giver's screens.
